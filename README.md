# LINO HP

美容室・サロン「LINO」の紹介ページ（学習用サンプル）。HTML/CSS/JSのみで作られた静的サイトです。

## ファイル構成

```
salon-site/
├── index.html      … トップページ
├── menu.html       … メニュー・料金ページ
├── access.html     … アクセス・店舗情報ページ
├── reserve.html    … 「ご予約」導線の案内ページ（学習用サンプルの説明）
├── style.css       … 全ページ共通のスタイル
├── script.js       … スマホ表示時のナビ開閉のみを行う最小限のスクリプト
├── *.jpg / logo.png … サイトで使う写真・ロゴ（すべてルート直下、写真は軽量化のためJPEG）
└── security-review.md … セキュリティ・堅牢性レビューの結果（ステップ4）
```

3ページとも同じヘッダー（ロゴ・ナビ・ご予約ボタン）とフッターを持つ、独立したHTMLファイルです。
共通部分をまとめるテンプレート機構は使っていないため、ヘッダーやフッターの文言を変える場合は3ファイルすべてに同じ修正を入れてください。

## ローカルで確認する方法

このフォルダで、パソコン上の簡易サーバーを起動してブラウザで開くと、CSS・フォントも含めて正しく表示されます（`file://`で直接開くとレイアウトが崩れる場合があります）。
サーバーの起動はAI（Claude Code）側で行えますので、「ローカルで見せて」と伝えてください。

## 内容を更新するときの目安

- 文章を直す：各HTMLファイルの該当箇所を直接編集
- メニュー・料金を直す：`menu.html` 内の `<table class="menu-table">` の行を編集
- 店舗情報を直す：`access.html` 内の `<table class="info-table">` の行を編集
- 配色・フォントを直す：`style.css` の `:root` 内の変数（`--color-navy` など）を編集すると、3ページ全体に反映される
- フォントは全ページ「メイリオ（Meiryo）」に統一している（`style.css` の `body { font-family }`）

## 画像について

サイト直下に、実際に使用する写真・ロゴを置いています。

| ファイル | 用途 |
|---|---|
| logo.png | 各ページのヘッダーロゴ（LINO） |
| hero.jpg | トップページのメイン写真 |
| staff-cut.jpg / staff-color.jpg | トップページのカード（施術シーン） |
| staff-portrait.jpg | トップページのスタッフ紹介カード |
| menu-cut.jpg / menu-color.jpg / menu-perm.jpg | メニューページのサムネイル |
| exterior.jpg | アクセスページの外観写真 |

写真を差し替える場合は、同じファイル名でサイト直下のファイルを上書きするだけで反映されます。
表示速度のため、写真はすべてJPEG（品質82〜85%程度）に変換して軽量化しています。ロゴは透明部分を保つため、余白を切り詰めたPNGのままにしています。

## サンプルサイトとしての注意

このHPは学習用サンプルのため、「ご予約・お問い合わせ」「ご予約はこちら」など予約につながるボタンは、すべて `reserve.html`（学習用サンプルであることを説明する案内ページ）にリンクしています。実際の店舗で運用する場合は、`reserve.html` へのリンクを、電話番号や予約システムのURLに差し替えてください。

## セキュリティについて

フォームや外部API連携を持たない静的サイトのため、ステップ4のレビューでは指摘事項はありませんでした。詳細は [security-review.md](security-review.md) を参照してください。
